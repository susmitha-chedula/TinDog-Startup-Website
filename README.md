# TinDog Startup Website

A fun and responsive startup landing page for a fictional dog dating app — TinDog.

## 🌐 Live Site
https://susmitha-chedula.github.io/TinDog-Startup-Website/

## 🛠️ Built With
- HTML5
- CSS3
- Bootstrap
- Responsive Web Design

## 📌 Features
- Hero section with app download buttons
- Features section (Easy to use, Elite Clientele, Guaranteed to work)
- Testimonials section
- Pricing plans (Chihuahua, Labrador, Mastiff)
- Press mentions (TechCrunch, Mashable, Business Insider, TNW)
- Responsive footer with navigation links

## 💡 About
Built to practice Bootstrap components, responsive layout, and modern landing page design.
